Code & data

Open-source estimators

The estimators behind my papers are public on GitHub under the MIT license. Each one turns a different kind of cosmological data into bispectrum measurements: galaxy fields for BARBIE, and radio-interferometer visibilities for ViBER and AMBER.

All repositories on GitHub ↗

Galaxy surveys

BARBIE

Brisk estimator for Angular multipoles of Redshift-space BIspEctrum

Takes a 3D cube of the galaxy density field and computes all the multipole moments of the redshift-space bispectrum, with redshift-space distortions taken along the z-axis.

Input
3D galaxy field cube
Output
Redshift-space bispectrum multipoles
GitHub ↗Paper: Phys. Rev. D 111, 043507 ↗

21-cm cosmology

ViBER

Visibility-based angular Bispectrum Estimator for Radio-interferometric data

Works on gridded visibilities from a single frequency channel and computes the angular bispectrum by correlating every triplet of baselines that closes into a triangle.

Input
Single-frequency gridded visibilities
Output
Angular bispectrum
GitHub ↗Paper: ApJ 979, 25 ↗

21-cm cosmology

AMBER

Accelerated multi-frequency angular and 3D bispectrum estimator

Extends the visibility-based approach across frequency. From gridded multi-frequency visibilities, it computes three-visibility correlations for every closed triangle of baselines, giving the multi-frequency angular bispectrum (MABS) and the 3D bispectrum.

Input
Multi-frequency gridded visibilities
Output
MABS and 3D bispectrum
GitHub ↗Paper: ApJ 995, 175 ↗
